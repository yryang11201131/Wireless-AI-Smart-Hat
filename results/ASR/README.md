\# ASR Results



Speech recognition experiments were conducted using 30 audio samples.



The compared approaches included:



\- Google Speech Recognition

\- Vosk

\- Whisper tiny



The purpose of the experiment was to compare recognition performance and determine a suitable ASR solution for the Raspberry Pi-based wearable system.



Whisper tiny through whisper.cpp was selected for the final implementation because it supports local and offline speech recognition.



Experimental figures and detailed records can be placed in this directory.
