\# YAMNet Experiment



This experiment evaluates environmental sound recognition for the Wireless AI Smart Hat.



\## Sound Categories



The evaluation includes four sound categories:



\- Alarm

\- Car Horn

\- Dog Bark

\- Background



\## Dataset



The experimental dataset was expanded through audio augmentation for model evaluation.



The four-class evaluation program is available at:



`../../src/YAMNet/yamnet\_fourclass\_evaluation.py`



\## Evaluation



The system evaluates the classification accuracy of each sound category and generates experimental results for further analysis.



The final YAMNet module is integrated into:



`../../src/Integrated\_System/vistra\_main.py`
