\# DoA Module



This directory contains the Direction of Arrival (DoA) module used in the Wireless AI Smart Hat.



The system uses a ReSpeaker USB microphone array to estimate the direction of incoming sound.



\## Main Functions



\- Read sound direction information from the ReSpeaker microphone array

\- Estimate the sound-source direction

\- Convert the estimated angle into user-friendly directions

\- Provide direction information to the LED indicator module



\## Direction Output



The integrated system simplifies the estimated sound direction into:



\- Front

\- Left

\- Right
