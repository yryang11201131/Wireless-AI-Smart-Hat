\# OLED Module



This directory contains the OLED display module used in the Wireless AI Smart Hat.



The system uses an SSD1322 OLED display to present speech subtitles, hazardous sound warnings, and sound-source direction information.



\## Main Functions



\- Display real-time speech transcription

\- Display hazardous sound warning messages

\- Display sound-source direction information

\- Provide visual feedback for hearing-impaired users



\## Display Device



\- SSD1322 OLED

\- Resolution: 256 × 64

\- Interface: SPI
