\# ASR Module



This directory contains the Automatic Speech Recognition (ASR) module used in the Wireless AI Smart Hat.



The current system uses Whisper through whisper.cpp for offline speech recognition on Raspberry Pi.



\## Main Functions



\- Capture speech audio from the microphone array

\- Convert speech into text using Whisper

\- Support offline speech recognition

\- Provide transcription results to the OLED display module



\## Current Model



\- Whisper tiny

\- whisper.cpp
